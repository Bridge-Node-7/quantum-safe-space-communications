# Public Claim Boundaries

## Supported descriptions

- Publicly distributable assessment and migration-planning framework
- Documentation-first methodology
- Evidence-first decision support
- Reference templates for post-quantum migration planning
- Internally reviewed repository release

## Unsupported descriptions

Do not claim that the repository or an assessment is:

- certified quantum-safe;
- independently validated without a published review record;
- compliant with a law, regulation, contract, or standard;
- operational authorization or authorization to deploy;
- flight qualified;
- a cryptographic implementation approval;
- proof of mission readiness;
- a prediction of Q-Day.

## Required qualification

State the scope, evidence, limitations, assessor, methodology version, and accountable authority when presenting results.

This framework does not provide certification or operational authorization.

## Publicly distributable

Content is publicly distributable only after privacy, security, export-control, contractual, intellectual-property, and mission-sensitivity review confirms that unrestricted publication is authorized. This label is not a security classification or legal determination.
