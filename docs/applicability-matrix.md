# Applicability Matrix

| Context | Primary considerations |
|---|---|
| Commercial operator | Contracts, customer commitments, product lifecycle, standards, interoperability, and sector obligations |
| Civil government | Agency policy, federal standards, acquisition rules, records, and public mission requirements |
| National Security System | Applicable CNSS/NSA policy, profiles, classified handling, authorization, and mission authority |
| Defense program | Contract clauses, program protection, acquisition authority, mission assurance, and controlled technical data |
| International or multinational mission | Participating agency standards, export controls, cross-support, data handling, and bilateral agreements |
| Research or demonstration | Explicit experimental boundaries, data handling, safety, and prohibition on operational overclaim |

Determine applicability with authorized legal, contracting, security, engineering, and mission authorities. This repository does not make that determination.
