# 09. Migration and Recovery Roadmap

## 0 to 30 days

Complete payload scope, reconcile command evidence, obtain vendor roadmaps, and approve data-protection horizons.

## 31 to 90 days

Select pilot profiles, test command authentication, secure update, interoperability, rollback, and key recovery.

## 3 to 12 months

Approve funded architecture, contract requirements, dual-stack exit criteria, deployment sequencing, and monitoring.

## Sustained operations

Exercise recovery, reassess evidence, monitor standards and vendors, retire legacy dependencies, and record exceptions.
