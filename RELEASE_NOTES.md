# Quantum Readiness for Space Communications v0.2.0

## Release summary

Version 0.2.0 is a breaking documentation-first correction of v0.1.5.

The release replaces the defective weighted readiness and average-risk methods with four separate decision inputs and the **Quantum Readiness Decision Pack**:

- Quantum Exposure Severity
- Migration Readiness Profile
- Evidence Confidence and Coverage
- Critical Risk Overrides

It includes a complete fictional example, lightweight methodology validators, 31 positive and adversarial tests, normalized external-link validation, deterministic packaging, and staged GitHub release controls.

## Public scope

This release does not contain an assessment engine, automated disposition, cryptographic implementation, public JSON decision schema, or workbook decision calculator.

## Historical preservation

The original v0.1.5 tag and release remain available. A supersession notice directs users to the v0.2.0 methodology and consolidated errata.

## Claim boundary

This release is not certification, compliance determination, operational authorization, flight qualification, product validation, or proof that a system is quantum-safe.
