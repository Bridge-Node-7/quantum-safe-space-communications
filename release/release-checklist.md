# Release Checklist

Use this checklist to preserve public release integrity.

## Source

- [ ] Methodology and mutation tests pass.
- [ ] Linux and Windows validation pass where supported.
- [ ] External links and structured files validate.
- [ ] Public-boundary and secret scans pass.
- [ ] Manifest, checksums, and deterministic package reproduction pass.
- [ ] Material limitations remain explicit.

## Publication

- [ ] Version and release metadata agree.
- [ ] Hosted validation passes on the reviewed source.
- [ ] The published tag corresponds to the reviewed release source.
- [ ] Public assets and checksums verify after publication.
- [ ] Logged-out public access is verified.

This checklist supports repository and release integrity. It is not system certification or operational authorization.
