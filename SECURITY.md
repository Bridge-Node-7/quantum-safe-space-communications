# Security Policy

## Reporting a vulnerability

Use GitHub Private Vulnerability Reporting from the repository **Security** tab. Provide only the minimum information necessary to understand and reproduce the issue.

Do not disclose sensitive security details publicly.

## Public corrections

Documentation, standards-status, methodology, accessibility, and template corrections may be proposed through a focused pull request using public-safe examples.

## Supported version

Security and methodology-integrity corrections are supported for the latest public release.
