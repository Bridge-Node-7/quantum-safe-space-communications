# Quantum-Safe Space Communications Readiness Index

## Purpose

The Quantum-Safe Space Communications Readiness Index scores an organization's readiness for quantum-era cybersecurity risk across space communications systems.

## Scoring Levels

| Level | Name | Description | Evidence Required |
|---|---|---|---|
| 0 | Unknown | No inventory, no crypto map, no assigned owners | Self-declaration only |
| 1 | Aware | Leadership recognizes quantum risk, but dependencies remain unmapped | Initial asset list and threat briefing |
| 2 | Mapped | Communications links, cryptography, vendors, and mission data flows are documented | Documented maps and data flows |
| 3 | Migration-Ready | PQC candidates, hybrid strategy, test plans, and procurement requirements are defined | Approved roadmap and pilot results |
| 4 | Quantum-Resilient | PQC is deployed across priority ground systems and planned for space systems | Operational hybrid systems and test data |
| 5 | Quantum-Safe Architecture | PQC, selective QKD where justified, QRNG, secure boot, key management, vendor assurance, and governance operate as one integrated architecture with audit evidence | Audit-verified evidence and monitoring |
