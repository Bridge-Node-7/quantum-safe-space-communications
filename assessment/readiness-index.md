# Historical Readiness Index Path

The weighted readiness index used in version 0.1.5 is retired.

Use the current [Migration Readiness Profile](migration-readiness-profile.md), which reports ten separate domains and does not produce a weighted aggregate or certification score.

The historical version 0.1.5 method must not be used for operational authorization, compliance determination, acquisition decisions, or claims that a system is quantum-safe.
