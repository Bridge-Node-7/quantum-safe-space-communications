# Code of Conduct

## Purpose

This project exists to improve public-safe, defensive, and evidence-based work on quantum-safe space communications.

Participants are expected to act with respect, professionalism, and care.

## Expected Behavior

- Be respectful and constructive.
- Keep discussions focused on defensive assessment, governance, and migration planning.
- Support claims with credible evidence when making technical or policy assertions.
- Respect public, private, proprietary, regulated, and sensitive boundaries.
- Use fictional or sanitized examples unless permission exists to share real information.
- Help improve clarity, safety, usability, and public value.

## Unacceptable Behavior

- Harassment, threats, or personal attacks
- Publishing credentials, keys, tokens, or private data
- Sharing proprietary, regulated, customer-sensitive, or controlled technical information
- Posting exploit code or operational targeting details
- Encouraging unauthorized access or live testing
- Misrepresenting speculative claims as confirmed facts

## Enforcement

Maintainers may remove comments, issues, pull requests, or contributions that violate this code of conduct or the project security policy.

Repeated or serious violations may result in blocked participation.

## Reporting

For security-sensitive concerns, follow `SECURITY.md`.

For general conduct concerns, contact the project maintainer through the appropriate private channel.
