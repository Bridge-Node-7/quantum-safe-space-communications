# Code of Conduct

## Our commitment

Participants in Quantum Readiness for Space Communications must contribute professionally, respectfully, and within the repository's publicly distributable scope.

## Expected behavior

- Use evidence-based, bounded language.
- Respect differing technical and policy perspectives.
- Protect confidential, mission-sensitive, customer, and vendor information.
- Use fictional or authorized examples.
- Report security-sensitive concerns privately.

## Unacceptable behavior

- Harassment, discrimination, intimidation, or personal attacks
- Publishing credentials, keys, tokens, controlled data, or sensitive architecture
- Presenting the framework as certification, authorization, or proof that a system is quantum-safe
- Submitting exploit instructions or live-targeting information

## Reporting

Report security-sensitive concerns through GitHub Private Vulnerability Reporting. Report conduct concerns to the accountable repository owner through a private channel.
