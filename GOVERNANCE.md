# Governance

## Stewardship

Bridge Node 7 maintains this public repository.

## Public change discipline

Changes should preserve:

- evidence-linked methodology;
- source and standards traceability;
- explicit unknowns and critical conditions;
- human decision authority;
- public claim boundaries;
- reproducible validation.

Methodology changes should be described in the methodology changelog. Security concerns should follow [`SECURITY.md`](SECURITY.md), and public contributions should follow [`CONTRIBUTING.md`](CONTRIBUTING.md).

Repository validation supports integrity of the public framework. It does not constitute independent validation, certification, or operational authorization.

## Change classes

- **Patch:** editorial, link, metadata, or non-breaking template correction.
- **Minor:** new or materially revised methodology preserving public claim boundaries.
- **Major:** incompatible method, scope, or output change.

See [Change Control](docs/change-control.md).
